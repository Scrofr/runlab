# RunLab

PWA mobile-first pour l'entraînement en course à pied et trail.

**Local-first** • IndexedDB • Design inspiré Bandit Running • Déployé sur GitHub Pages

## URL

https://scrofr.github.io/runlab/

## Fonctionnalités

- **Niveau** : évaluation VDOT (route) + allure trail ajustée D+
- **Séances** : création de workouts structurés (blocs warmup/work/recovery)
- **Plans** : planning hebdomadaire basique
- **Minuteur** : fractionné plein écran + Web Audio
- **Progrès** : historique évaluations + volume
- Export / Import JSON

## Stack

Svelte 5 + Vite • IndexedDB maison • Service Worker • uPlot ready

## Développement

```bash
npm install
npm run dev
```

Build : `npm run build` → dossier `dist` (base `/runlab/`)
